# 🧠 Estudos de Lógica de Programação com Python

Projeto prático desenvolvido para consolidar conceitos de Lógica de Programação utilizando a linguagem Python.

## 🚀 Funcionalidades & Diferenciais
- **Menu Interativo (CLI):** Arquivo `main.py` que centraliza a execução de todos os exercícios.
- **Modularização:** Algoritmos divididos em funções reutilizáveis.
- **Tratamento de Erros:** Validação de entradas utilizando blocos `try/except`.
- **Type Hints:** Declaração explícita de tipos nos parâmetros das funções.

## 🛠️ Tecnologias
- **Python 3**
- **Git & GitHub**
